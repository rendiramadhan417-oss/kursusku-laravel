\# Refleksi Praktikum Laravel — KursusKu rendy ramadhan



Pada praktikum ini, saya belajar membuat halaman website menggunakan framework Laravel. Saya memahami bahwa route berfungsi mengarahkan request ke controller yang sesuai. HomeController digunakan untuk menyiapkan data kursus yang akan ditampilkan. Data tersebut kemudian dikirim ke view Blade untuk menghasilkan halaman HTML. Saya juga belajar menggunakan CSS untuk mempercantik tampilan dan membuat website lebih responsif pada layar HP. Selain itu, saya belajar menggunakan Git untuk menyimpan riwayat perubahan proyek. Praktikum ini membantu saya memahami dasar alur kerja Laravel dan pentingnya memeriksa hasil program melalui browser dan terminal.
