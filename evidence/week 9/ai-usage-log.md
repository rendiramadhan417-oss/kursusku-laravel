
# AI Usage Log - Week 09

## 1. Tujuan
AI digunakan sebagai alat bantu untuk memahami dan menyelesaikan praktikum Laravel Week 09, khususnya dalam pembuatan layout Blade, penggunaan Bootstrap, integrasi jQuery, dan fitur Ajax untuk mengecek ketersediaan kursus.

## 2. Prompt Penting
- Membantu menghubungkan Bootstrap dan jQuery melalui Vite.
- Membantu membuat master layout dan navbar pada Laravel.
- Membantu memperbaiki tampilan halaman beranda dan form pendaftaran.
- Membantu membuat fitur pengecekan sisa kursi menggunakan jQuery Ajax.
- Membantu mengatasi kendala saat menjalankan project Laravel.

## 3. Saran yang Diterima
- Menggunakan master layout agar tampilan halaman lebih konsisten.
- Menggunakan Bootstrap untuk membantu membuat desain halaman.
- Menggunakan jQuery Ajax untuk mengambil data ketersediaan kursus.
- Menggunakan @csrf pada form pendaftaran.
- Menggunakan response JSON dari route Laravel untuk menampilkan sisa kursi.

Saran tersebut digunakan karena sesuai dengan tujuan praktikum Week 09.

## 4. Saran yang Tidak Digunakan
Beberapa saran tambahan terkait instalasi package opsional tidak diterapkan karena tidak diperlukan untuk menjalankan fitur utama praktikum.

## 5. Verifikasi
Setelah menerapkan saran AI, dilakukan pemeriksaan dengan cara:
- Menjalankan aplikasi Laravel.
- Membuka halaman beranda dan pendaftaran.
- Memilih kursus Web Dasar, PHP Dasar, dan Laravel Dasar.
- Memeriksa perubahan jumlah kursi.
- Memeriksa request Ajax melalui Developer Tools pada tab Network.

## 6. Kesimpulan
AI digunakan sebagai pendamping dalam proses pengerjaan dan pemecahan masalah. Setiap perubahan kode tetap diperiksa dan diuji secara langsung pada project KursusKu.
